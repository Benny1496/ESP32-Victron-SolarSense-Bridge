# Contributing (English)

Bug reports, pull requests, compatibility information, docs and practical improvements are welcome.

- Describe tested ESPHome/Venus OS versions and hardware, and distinguish observed behavior from assumptions. Remove private addresses, tokens, certificate details and raw logs.
- Prefer focused changes. Do not accidentally break the existing BLE proxy, Home Assistant measurement updates or Cerbo forwarding.
- Run C++ checks and an isolated ESPHome build where possible. Never claim real-hardware verification based only on static tests.
- Third-party code requires complete authorship, copyright, license and required NOTICE records. Do not include private device or personal data.
- Pull requests are welcome in **German or English**; try to update user-facing guidance in both languages when changing behavior.

Original contributions are licensed under GPL-3.0-only unless explicitly and compatibly stated otherwise.
