# Home-Assistant-Anzeigen und Übersetzungen (Deutsch)

[Deutsch](HOME_ASSISTANT.de.md) · [English](HOME_ASSISTANT.en.md) · [Startseite](../README.md)

## Warum die Entitäten weiterhin deutsche Namen haben

Die veröffentlichte ESPHome-Vorlage basiert auf der produktiv verwendeten 4.3.1. Damit bestehende Entitätskennungen, Automationen und Dashboards bei einer späteren Übernahme nicht unnötig geändert werden, wurden die deutschen Anzeige- und Quellcode-Namen nicht automatisch umbenannt. **Die Dokumentation ist zweisprachig; eine automatische Sprachumschaltung in Home Assistant ist nicht eingebaut.**

| Bestehende Anzeige in Home Assistant | Englische Bedeutung |
|---|---|
| Victron Bridge mit Cerbo koppeln | Pair Victron Bridge with Cerbo |
| Victron Bridge Übertragung aktiv | Victron Bridge forwarding enabled |
| Victron Bridge BLE-Pakete jetzt senden | Send Victron Bridge BLE packets now |
| Victron Bridge Cerbo HTTPS Verbindung testen | Test Cerbo HTTPS connection |
| Victron Bridge erfolgreiche Übertragungen | Successful transmissions |
| Victron Bridge Übertragungsfehler | Transmission errors |
| Victron Bridge Übertragungsstatus | Forwarding status |
| Victron Bridge Kopplungsstatus | Pairing status |
| SolarSense Südost | SolarSense Southeast (sensor 1) |
| SolarSense Nordwest | SolarSense Northwest (sensor 2) |
| Bestrahlungsstärke | Irradiance |
| Geschätzte Leistung | Estimated power |
| Heutiger Ertrag | Today's yield |
| Zelltemperatur | Cell temperature |
| Letzter Empfang | Last received packet |
| Letzte Sonne | Last sunlight |
| Gültige BLE-Pakete | Valid BLE packets |
| WLAN-Signal | Wi-Fi signal |
| Laufzeit | Uptime |

**Hinweis:** „Südost“ und „Nordwest“ sind Bezeichnungen aus dem ursprünglichen Zwei-Sensor-Projekt, **keine echten veröffentlichten Adressen oder erkannten Dachrichtungen**. Wer individuelle englische Anzeigen möchte, kann die **freundlichen Namen in Home Assistant** anpassen. Interne ESPHome-IDs nicht unüberlegt ändern, da Automationen und Ausdrücke darauf verweisen können.
